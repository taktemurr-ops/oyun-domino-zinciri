# Domino Zinciri · Domino Chain

Taşları diz, ilk itişle zil çalsın

Sarı taş ok yönünde devrilir. Boş karelere dokunarak düz taş ya da sola, sağa döndüren köşe taşı yerleştir; tekrar dokunmak türünü değiştirir. Elindeki taş sayısı üstte yazar, sabit taşlar değişmez. Hazır olunca Başlat’a bas: zincir zile ulaşmalı.

100.000 bölüm; her bölüm üretilir ve kurallara göre doğrulanır. Özgün Oyunlar merkez uygulamasının oyunu; ortak motor: [ozgun-motoru](https://github.com/taktemurr-ops/ozgun-motoru).
